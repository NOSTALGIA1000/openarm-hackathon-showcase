# OpenArm｜物理抓取仿真与接触诊断

地瓜机器人黑客松 2026 · NOSTALGIA1000 项目作品集

这个项目研究一个具体问题：**机械臂完成了预定轨迹时，夹爪真的能靠接触把物体夹起来吗？** 我在 OpenArm、MuJoCo 和 ROS 2 的实验流程中，用双侧接触、抬升高度和保持阶段的数据来判断抓取结果。

## 实验怎么做

1. 在 MuJoCo 中运行接近、夹爪闭合、抬升和保持流程，按阶段观察双指同帧接触与物体高度。
2. 固定随机种子，组合 **4 档夹爪闭合行程 × 3 种方块宽度 × 3 档滑动摩擦参数**，共 36 个仿真条件。
3. 以静置后的物体高度作为基线。只有达到规定高度并且维持双侧接触的样本，才进入扰动保持评估。

## 仿真结果

| 指标 | 结果 |
| --- | ---: |
| 运动流程报告完成 | 36/36 |
| 达到最终抬升阈值 | 0/36 |
| 达到扰动评估前置条件 | 0/36 |
| 满足稳定抓取判据 | 0/36 |
| 最大瞬时抬升 | 约 4.95 mm |
| 稳定抓取的抬升阈值 | 50 mm |

相同协议的两次运行得到字节一致的结果表和摘要。在当前模型和测试范围内，夹爪未建立有效的双侧接触，因此后续工作聚焦夹爪表面几何、闭合方式和接触形成。ROS 2 课程流程也做了复现，其中物体移动由控制器和软件跟随产生。上表只报告 MuJoCo 探索性筛查结果。

## 下一步

用自由刚体物体和受限动力学滑动夹爪重建实验，记录抓取力、抬升和相对滑移。先验证能否抬升 20 mm 并保持 2 s，再引入手眼标定偏差与抓取前视觉修正。这套验证思路也用于黑客松拟做的微型夹爪：先确认物体在夹爪内稳定，再尝试更精细的 USB‑C 接触和插接动作。
